DeepSeek Harness 插件：为每次 `edit` / `write` / `str_replace_editor` 调用在对话中就地渲染内联差异卡片，自动识别文件语言（57 种）并做避开红绿的语法高亮，并提供左右对照、行内字符级高亮、移动块与被动行号说明、Read 行范围展示；命令、搜索、网页与通用工具调用还可切换为默认展开 IN/OUT 的「展开风格」，命令与工具卡片的输入/输出状态按段独立着色。**1.3.0 起界面与文档提供完整中英双语，并可在设置页独立切换语言；1.4.0 起默认「跟随 DSH」，并新增卡片/输出/弹窗动效以及设置页自带的版本检查、更新与回退。**

## 兼容性

- **DSH 版本范围（`engines.dsh`）**：`>=0.2.2-rc.1 <0.3.0`
- **实测版本**：`0.2.2-rc.1`（桌面端 profile）与 `0.2.2-rc.2`（Web profile）
- 不在 `engines.dsh` 范围内时，DSH 加载器会拒绝加载本插件，不会静默运行未验证版本
- 桌面端与 Web UI 若使用不同 profile，需要分别安装
- 不 shadow `conversation.chat.node` 的 tool-call 条目（官方 Tool 层拥有该条目并声明 `tool.call.toolview` 子槽，重复声明会抛错），只通过 keyed `tool.call.toolview` 注册接管已登记的工具行；未登记工具沿用官方通用行
- 与启动动画类插件互不接管 slot；动画关键帧使用独立命名空间（`dsh-inline-diff-*`），Read 范围观察器只响应 Read 行相关 DOM 变更，避免抢占启动动画的主线程
- 与第三方主题共存：keyed `tool.call.toolview` 使用 priority `-100`，避免与同样注册工具视图的主题插件（如 claude-style 在 `-1` 注册）发生重复 key 冲突；卡片头部带 `aria-haspopup="false"` 豁免并只响应真实用户手势，避免主题在折叠动画结束时重放合成点击、把「放大 / 轨迹 / 文件路径」的点击变成折叠卡片

## 安装

在 DSH 中从 npm 安装（推荐）：

```bash
dsh plugin add @him666233/dsh-inline-diff
```

也可以在 DSH Web UI 的「插件 → 添加插件」里直接输入包名安装。桌面端与 Web UI 若使用不同 profile，需要分别安装；插件加载后刷新或重启 DSH。npm 包名同时写在本包的 `cordis.patch.yml`（bundle 插件的模块名）与 `client.js`（浏览器模块 id）里，请勿只改其中一个。

其他安装方式（旧方式继续可用）：

- **本地目录 / 离线安装**：把本目录（`plugin/`）交给 DSH「插件 → 添加插件」（输入绝对路径），或解压 Release 中的 `dsh-inline-diff-<版本>-plugin.zip` 后选择解压出的 `plugin/` 目录；
- **手动 link（开发调试）**：见下方；
- **升级**：`dsh plugin add @him666233/dsh-inline-diff@<版本>`，或在插件页卸载后重装；**卸载**：`dsh plugin remove @him666233/dsh-inline-diff`（或插件页卸载）。同一个 profile 不要同时保留 link 版与 npm 版。

本地开发或离线安装：把本目录（`plugin/`）作为本地插件安装，或手动 link：

```bash
cd ~/.dsh/profiles/<profile>
pnpm add link:/absolute/path/to/dsh-inline-diff/plugin
```

然后在 profile 的 `package.json` 中加入：

```json
{
  "dependencies": {
    "@him666233/dsh-inline-diff": "link:/absolute/path/to/dsh-inline-diff/plugin"
  },
  "dsh": {
    "profile": {
      "bundles": ["@him666233/dsh-inline-diff"]
    }
  }
}
```

## 功能

- edit / write / str_replace_editor 逐次内联差异，精确旧/新行号；每个修改点的行号列上方带「旧 / 新」图例（与行号列严格对齐；新建文件等只有一侧行号的修改点只显示对应一侧图例），删除行旧行号染红、增加行新行号染绿并加粗；
- 紧凑行号栏与更清晰的卡片边框：内容内缩、代码起点更靠左，新增/删除色条仍通栏到边缘；
- 行内字符级高亮，只有真正变化的片段标深红/深绿；同一处替换中共享的空白与标点并入改动区，连成连续高亮带，孤立的空白/标点差异不会被误标；
- 移动块标注「移至/移自 旧/新 Lx–Ly」（单行移动按显示宽度判定，≥12 格才标注）；被动行号位移说明 `旧 Lx–Ly → 新 Lm–Ln · 行号顺延 ±N`；
- 左右对照弹窗与全文对照（依赖 Host 内存快照）；变更块模式按修改点分组、横条吸顶，历史回放等说明横幅与「修改前/修改后」栏固定在标题下方，滚动条只属于对比内容区域；
- 固定文件/修改点表头；Read 行折叠时在文件名旁显示实际行范围（多段用 ` · ` 分隔，最多 4 段后省略），展开后保留 DSH 原生展示；
- 自动识别文件语言（57 种，按扩展名、特殊文件名与 shebang 首行），在卡片头部与放大弹窗显示语言徽章（短代码 / 全名 / 隐藏；「隐藏」隐藏全部徽章；徽章可见时未知语言可显示虚线徽章；纯文本显示「纯文本」标记）；
- 逐语言语法高亮：内联卡片与左右对照弹窗的代码行统一着色；配色限定在蓝→紫区间（色相 180°–285°）并刻意避开红/绿/橙/黄/品红，避免与新增/删除标记混淆；每个前景色在官方深色/浅色代码底色上对比度 ≥ 4.5:1；关闭高亮、未知语言或纯文本时回退默认前景色（跟随浅色/深色外观）；
- 语法高亮四项设置：开启/关闭、语言标识（短代码/全名/隐藏）、未知语言（显示/不显示）、字体强调（颜色+字体样式/仅颜色：关键词等加粗、注释斜体）；设置页内可展开查看支持的 57 种语言；
- grep / glob / web_search / web_fetch 与普通工具调用共用展开风格：类别图标、关键词/路径/URL 摘要、匹配数/文件数/来源数/HTTP 状态徽标、默认展开 IN/OUT；
- 内联差异卡片与所有展开风格工具行使用统一的「轨迹」胶囊按钮；
- 命令执行与工具调用卡片的左侧色条按 IN/OUT 分段独立显示状态：IN 准备/等待输出=主题色（脉动）、输入侧完成=绿、输入侧失败=红；OUT 执行中=主题色（脉动，含「执行中…」占位）、输出成功=绿、执行失败/非零退出=红、用户中止=警告色；失败按错误码归因到输入侧或输出侧（缺少错误码时按原始参数是否合法 JSON 回退判定），输入侧失败时 OUT 标为「跳过」；输入侧失败时 IN 代码红字、输出侧失败时 OUT 代码红字，正常文字跟随内部配色与明暗外观；
- 文件修改、命令执行、其它工具调用三类卡片都使用「外壳 + 内部」双色结构；外壳跟随当前主题（含第三方主题）——派生颜色在 `body` 层解析，官方原版主题（token 在 `body`）与皮肤主题（token 在 `:root`）都能正确跟随，切换后不会残留上一个主题的色调；内部使用官方明暗外观的代码块底色与对应字色；三类卡片可分别配置外壳/内部配色（外壳：自动 / 浅色 / 深色；内部：自动 / 浅色 / 深色 / 与外壳一致）；
- 读取宿主实际明暗外观（浅色 / 深色 / 跟随系统），卡片与设置窗口自动使用可读的底色和字色，第三方主题切浅色时也不会浅底浅字；弹窗与卡片均为不透明表面，不会透出壁纸；
- 四项独立展示选项：文件卡片、命令执行行、其它工具调用、过程折叠；设置弹窗标题栏固定、内容独立滚动，滚动条按区域贴边或内缩。

## 设置

侧边栏底部「差异样式」或 DSH 设置页「内联差异」：

**界面语言（1.3.0 新增，1.4.0 起默认跟随 DSH）**：

| 设置项 | 可选项 |
| --- | --- |
| 界面语言 / Language | 中文 / English / **跟随 DSH（默认）** |

切换立即生效、无需刷新，不会改动 DSH 全局语言；默认跟随 DSH（DSH 中文时中文，其它语言时英文）；旧存档中从未明确选择过语言的会一次性迁移为跟随 DSH，曾明确选过的保留。文档语言：中文默认（本文件），英文见 [README.en.md](README.en.md)。设置页顶部同时展示一条醒目的原创声明：本项目为完全原创作品，与任何同名/相似插件（包括 [JanEickholt/dsh-inline-diff](https://github.com/JanEickholt/dsh-inline-diff)）没有任何关系。

**版本与更新（1.4.0 新增）**：

| 操作 | 说明 |
| --- | --- |
| 检查更新 | Host 侧读取 npm 上 `@him666233/dsh-inline-diff` 的全部版本（60 秒缓存），标记最新 / 当前 / 已废弃 / 不可安装 |
| 更新 / 回退 / 重装 | 选择任意版本后按版本关系显示对应动作；Web 端一键调用官方插件安装命令（失败自动回滚并显示日志），成功后提示重启 DSH；桌面端显示可复制命令（需先完全退出 DSH） |

四项展示风格：

| 设置项 | 展开风格 / 不折叠 | DSH 原生 |
| --- | --- | --- |
| 文件修改卡片 | 本插件的内联差异卡片 | 官方文件修改行 |
| 命令执行行 | 默认展开 IN/OUT 的扁平命令行 | 官方 bash / pwsh / win_bash 行 |
| 其它工具调用 | 普通/详情/搜索/网页类工具默认展开 IN/OUT | 官方卡片 |
| 过程折叠 | 写入 DSH verbose 偏好 | 保留用户已有偏好 |

开启「其它工具调用 → 展开风格」时，若「过程折叠」仍为 DSH 原生，插件会自动把它切到「不折叠」，否则已完成的工具行会被 DSH 折叠组遮住。

语法高亮与语言徽章（独立于上表）：

| 设置项 | 可选项 |
| --- | --- |
| 语法高亮 | 开启 / 关闭 |
| 语言标识 | 短代码 / 全名 / 隐藏 |
| 未知语言 | 显示“未知语言” / 不显示 |
| 字体强调 | 颜色 + 字体样式 / 仅颜色 |

设置保存在 localStorage（`dsh-inline-diff.settings.v5`）；旧 v4 / v3 / v2 值自动迁移并删除旧键。默认界面语言为「跟随 DSH」。

## 数据与限制

插件默认没有网络请求或遥测，客户端不使用 `innerHTML` / `dangerouslySetInnerHTML` / `eval`；唯一例外是用户主动点击「检查更新 / 安装」时 Host 访问 npm registry 并调用本机 `dsh` CLI，请求只含包名/版本号，不发送会话内容、文件内容、密钥或设备信息。Host 只保留显示所需的修改前后文本到内存快照（LRU：最多 240 条、每侧上限 4MB，并限制总量 64MB），不落盘；Host 只读 API 受 DSH 浏览器信任边界（`connection` 准入，无该服务时回退本机 loopback 围栏）保护，并有请求体 1MB、仅 JSON、10 秒读取超时、15 秒文件读超时与 8 并发上限。超大文件与超大单行在浏览器侧有物化预算（20 万行 / 单行 100 万字符），超限自动降级为差异块并提示原因，不会冻结页面。Host 只为 `edit` / `write` 保存快照，`str_replace_editor` 按工具元数据中的修改块展示并尽量定位行号，卡片与放大弹窗用「不保存执行快照」的专用说明（不是历史回放措辞）；应用重启后的历史回放同样会在放大弹窗内说明。极端情况下按「快照 → 当前文件读取 → 工具元数据差异块 → 明确说明」逐级回退；界面语言、设置存储、语法高亮同样有中文 / 默认值兜底，最终才显示可读的错误说明而不是静默失败。历史回放的行号按当前文件重新定位；若文件此后又被改动导致无法唯一定位，会显示「行号待定」并在弹窗说明只展示修改块。同一张卡片展示的是该次编辑的执行快照，不会随文件后续改动刷新；完整的显示行为说明（快照语义、刷新规则、行号图例、弹窗层级与滚动、性能提示）见仓库 [docs/display-behavior.md](https://github.com/Him666233/dsh-inline-diff/blob/main/docs/display-behavior.md)。

动效方面：只给运行中卡片挂载、输出出现与弹窗打开加克制动画，历史回放与已结算卡片直接显示终态，系统「减少动效」下全部关闭。

版本与更新方面：更新面板列出的是 npm 已发布版本；一键安装会用发布版覆盖当前 profile 中的安装（本地开发构建会被覆盖），安装后必须重启 DSH 生效；桌面端 v1 不提供运行中一键安装，只显示手动命令。

完整说明、内部架构与已知限制见仓库根目录 [README](https://github.com/Him666233/dsh-inline-diff#readme)。
